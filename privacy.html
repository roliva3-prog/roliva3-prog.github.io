Privacy Policy

Personal File Mirror is a personal-use application operated by one individual.

Information Accessed

The application uses rclone to access files and folders in Microsoft OneDrive and Google Drive for file copying and backup.

How Information Is Used

File information and contents are used only to perform transfers between cloud storage accounts controlled by the application owner.

Storage and Sharing

Files remain in the owner's cloud storage accounts. This website does not host personal files. Google user data is not sold or used for advertising.

Security and Access

Access credentials are stored locally by rclone. The owner may revoke Google access through their Google Account security settings.

Contact

Privacy questions may be directed to the support email listed on the application's Google consent screen.
